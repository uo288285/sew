Ayuda de MotoGP-Desktop

En esta página web puedes encontrar las siguientes secciones por las que navegar:

Inicio

Esta página de inicio te ofrece acceso rápido a toda la información sobre MotoGP y el sitio web. En la parte superior de la página encontrarás el menú de navegación con enlaces a todas las secciones del sitio.

El carrusel muestra imágenes destacadas de MotoGP que cambian automáticamente cada pocos segundos. Debajo del carrusel encontrarás las últimas noticias sobre MotoGP. Haz clic en "Leer más" para ver la noticia completa.

Puedes navegar por el menú usando la tecla Tab. Todas las imágenes tienen descripciones alternativas para lectores de pantalla, y la página se adapta automáticamente a móviles y tablets.

Piloto

Esta página muestra información completa sobre Maverick Viñales: biografía, datos personales, equipos, estadísticas y trayectoria profesional. Incluye imagen y vídeos sobre él, también hay una tabla con sus resultados de la última temporada, además de una explicación de términos técnicos sobre la MotoGP. Existen enlaces a páginas externas para que puedas obtener más información sobre la vida del piloto y su carrera.

Circuito

En esta página podrás cargar archivos que contienen información sobre el circuito de Sepang, en Malasia. Puedes cargar un archivo HTML con datos generales, un gráfico de altimetría en formato SVG y un archivo KML para visualizar el trazado en Google Maps. Te recomendamos usar la vista de satélite para una mejor experiencia.

Meteorología

En esta página podrás ver datos meteorológicos tanto de los días de entrenamiento previos a la carrera como del momento en que se inició. Además, podrás encontrar también información sobre la ciudad de Kuala Lumpur, próxima al circuito.

Clasificaciones

En esta página podrás ver datos como el ganador de la carrera y el tiempo que tardó en cruzar la meta, así como la clasificación del mundial tras la carrera.

Juegos

En esta página podrás ver una selección de juegos.

Juego de memoria con cartas

Al entrar en este juego se inicia un cronómetro que no se detendrá hasta que consigas emparejar las 12 tarjetas de memoria. Destapa de dos en dos las tarjetas para intentar formar parejas. Si fallas se volverán a voltear, si aciertas se mantendrán descubiertas. Cada vez que entres, las cartas estarán en posiciones distintas.

Cronómetro

Tiene tres botones, uno para arrancar el cronómetro, otro para pararlo y otro para reiniciarlo, en todo momento se muestra el tiempo que va transcurriendo con el cronómetro iniciado.

CronómetroPHP

Tiene tres botones uno para arrancar, otro para parar y finalmente tiene otro para mostrar el tiempo una vez que se ha parado el tiempo.

Configuración Test

Utilizado por el personal de la aplicación para la realización de test de usabilidad, en este caso para su preparación y configuración. No está hecha para ser usado por personas externas a la aplicación.

Test

Utilizado por el personal de la aplicación para la realización de test de usabilidad, en este caso para que las personas puedan realizar el test contestando a las preguntas y posteriormente puedan añadir comentarios y valoren la aplicación. No está hecha para ser usado por personas externas a la aplicación.
